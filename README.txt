Files:
- index.html: website
- profile.jpg: portrait cropped from your supplied resume

HOW TO VIEW:
1. Extract the ZIP file.
2. Open index.html in a browser (Chrome is fine).

HOW TO PUBLISH FOR FREE:
1. Sign in to GitHub and create a new public repository.
2. Upload index.html and profile.jpg to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to provide your website link.

Please check the education institution name and year before publishing; I kept them close to the wording in your resume. Your phone and email are visible on the site, so remove them if you prefer not to share them publicly.
